## How I work

- **Security by default**: hashed passwords, JWT, parameterised queries, secrets kept in environment variables
- **Tested**: backends are tested against real databases running in Docker
- **Documented and reproducible**: every project has a README with setup steps; backend projects include a schema and an example `.env`
- **International**: user interfaces and documentation in English, with several projects available in German and Polish
